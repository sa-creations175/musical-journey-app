Chord Cell Drill Grid

Clicking a scales cell offers left, right and both. Clicking a chord shape cell offers inversions and no hand choice at all. This makes the two consistent: inversions down the side, hands across the top, one click to drill any combination.

What Changes

Three things, one of them a removal.

Add

Hand columns. Every inversion can be drilled left, right or both — the same three choices the scales cell already offers.

Change

The badge shows the rating. Needs Work, Developing, Fluent, Mastered, Started, Not Started — the same four-plus-two vocabulary as everywhere else. No separate acquisition word.

Cut

The self-assessment prompt goes. "How well do you know this?" with Not started / Familiar / Comfortable is retired. It was what made a chord read Acquired and never at the same time.

What Sits In A Cell

Two facts, stacked. Nothing else fits at this size, and nothing else is needed to decide what to drill.

The rating

Coloured square and word. Needs Work, Developing, Fluent, Mastered — plus Started below the floor, and Not Started for never met.

Last drilled

In words, from the drill log. 3d ago or never. Read live, not from a cache.

The cell is the button

Clicking anywhere in it starts that drill. Hover and keyboard focus both show it clearly.

Rules For The Build

Everything below holds regardless of layout choices.

  1. One vocabulary on screen. The cell shows a rating. It never shows an acquisition stage. "Acquired" leaves the interface.
  2. Hands come from the catalog. Left, right and both are existing drills, not new ones. If a combination has no catalog entry, say so rather than inventing it.
  3. The two-handed exercise stays reachable. Root in the left hand, inversions up and down in the right. Sevenths only. It sits below the grid, keeps its own Drill button, and never grows hand columns.
  4. Last drilled reads the drill log directly, not the cached field — the cache was going stale while badges updated.
  5. Scales cells are untouched. This changes the chord shape cell only.
  6. Title Case for labels and buttons, per the app-wide rule. Chord names keep their real notation — Cmaj7 is not retyped.

Decided — clearing the old declarations

Retiring the prompt stops new declarations. The ones already stored get cleared too, so every chord starts from what has actually been drilled. Coverage numbers and the session generator will both move as a result. Report the count before clearing anything — how many rows carry a declared stage with no reps behind it — the same way the settings page previews a recalculation before it runs.
